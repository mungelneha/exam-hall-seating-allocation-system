# Exam Hall Seating Allocation System

##  Project Overview
The Exam Hall Seating Allocation System is a desktop-based software application developed to automate and manage the process of assigning seats to students during examinations.

The system reduces manual effort, improves accuracy, and manages student, exam, and hall data efficiently.

##  Features
- Student Management
- Exam Management
- Hall Management
- Automatic Seat Allocation
- Seating Arrangement Reports
- Secure Admin Login
- Database Management using MySQL

##  Technologies Used
- Java (Swing)
- JDBC
- MySQL
- VS Code / IntelliJ IDEA

##  Modules
- Login Module

##  Functionalities
- Add, Update, Delete Student Records
- Manage Exam Details
- Manage Hall Capacity

- Generate Seating Reports

##  Objectives
- Reduce manual workload
- Improve seating accuracy
- Automate exam seating process
